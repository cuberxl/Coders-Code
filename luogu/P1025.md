### P1025 [NOIP 2001 提高组] 数的划分
---

**难度**：$\mathit{\color{yellow}{普及}}$

做法一：DFS （上下界剪枝）
- 下界：不降原则
- 上界：剩 $k - u + 1$ 个数要选，当前选 $i`，后面每个数至少是 `i`
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 1e3 + 10;
int n, k, ans;
int a[N];
void dfs(int u, int lst, int sum)
{
    if (u > k)
    {
        if (sum == n)
            ans ++;
        return;
    }
    if (sum >= n && u <= k)
        return;
    for (int i = lst; i <= (n - sum) / (k - u + 1); i ++)
        dfs(u + 1, i, sum + i);
}
int main()
{
    cin >> n >> k;
    dfs(1, 1, 0);
    cout << ans;
	return 0;
}
```

做法二：动态规划
**分析：**
- 状态表示：设 $f[i][j]$ 为把 $i$ 个数分为 $j$ 个数的方案数。
- 初始值：$f[i][1]=1$
- 状态转移：依据当前状态是否包含 $1$ 来划分子集。
	- 包含：$f[i][j]=f[i-1][j]$ （减去这个 1）
	- 不包含：$f[i][j]=f[i-j][j]$ （每一个数字同时 $-1$）
- 递推式：$f[i][j]=f[i-1][j]+f[i-j][j]$ (仅当 $j \leq i$)

**误区**：
- 错误递推式：$f[i][j]=f[i-1][j]+f[i-1][j]$ (仅当 $j \leq i$)
- 其依据最后一个数是否为 $1$ 划分，但这样 $-1$ 的不同时刻便有了差别，是有序拆分。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 1e3 + 10;
int n, k, ans;
int f[N][N];//i分j
int main()
{
    cin >> n >> k;
    for (int i = 1; i <= n; i ++)
        f[i][1] = 1;
    for (int i = 2; i <= n; i ++)
        for (int j = 1; j <= min(k, i); j ++)
            f[i][j] = f[i - 1][j - 1] + f[i - j][j];
    cout << f[n][k];
	return 0;
}
```
