### P7075 [CSP-S 2020] 儒略日
---

**难度**：$\mathit{\color{green}{普及+/\ 提高-}}$

策略：模拟，打表。

在格里高利历中，年份的日期变化 $400$ 年一循环。
预处理这 $400$ 年中的年份**变化量**，该年的月份和天数。
方便闰年计算，公元前 $n$ 年转化为 $1-n$ 年。

计算可得儒略历最后一天的儒略日为 $2299160$，由此区分格里高利历和儒略历。

对于儒略历，将起点为公元前 $4713$ 年（不跳过）。
对于格里高利历，将起点回调到第一个 $400$ 的倍数 $1200$ $^1$。
此时跳过了 $2159351$ 天，减去。

查表输出相对应的年月日即可$^2$。

误区：

Q1：这里格里高利历回调的起点有一部分和儒略历重合，不会错误吗？
A1：不会。格里高利历读表的时候读的是格里高利历的表，不会被儒略历影响。儒略历直接进入儒略历分支，也不会受影响。

Q2

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int A=146097,B=1461;
int y[A],m[A],d[A];
int m_d(int y,int m)
{
    if (m==2)
    {
        if ((y%4==0&&y%100!=0)||(y%400==0))
            return 29;
        else
            return 28;
    }
    if (m==4||m==6||m==9||m==11)
        return 30;
    return 31;
}
signed main()
{
    m[0]=d[0]=1;
    for (int i=1;i<A;i++)
    {
        d[i]=d[i-1]+1,m[i]=m[i-1],y[i]=y[i-1];
        if (d[i]>m_d(y[i],m[i]))
            d[i]=1,m[i]++;
        if (m[i]>12)
            m[i]=1,y[i]++;
    }
    int t;
    cin>>t;
    while (t--)
    {
        int r; cin>>r;
        int base_y=0;
        if (r>2299160)
        {
            r-=2159351;
            base_y=1200+r/A*400;
            r%=A;
        }
        else
        {
            base_y=-4712+r/B*4;
            r%=B;
        }
        int ans_y=base_y+y[r],ans_m=m[r],ans_d=d[r];
        if (ans_y>=0)
            cout<<ans_d<<' '<<ans_m<<' '<<ans_y<<'\n';
        else
            cout<<ans_d<<' '<<ans_m<<' '<<1-ans_y<<" BC"<<'\n';
    }
    return 0;
}
```
