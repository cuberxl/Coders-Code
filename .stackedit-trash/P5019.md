### P5019 [NOIP 2018 提高组] 铺设道路
---

**难度**：$\mathit{\color{yellow}{普及}}$

**策略**：贪心。

从左往右遍历每个坑。

考虑到当我们填一个坑时，这个坑的左边有一个小的，填这个小坑的时候，这个大坑的 $a[i-1]$ 层可以被顺便填好。必须花费的钱是 $a[i]-a[i-1]$（这部分不能被顺便填掉，得花时间）。

**误区**：
Q1：这和题目的区间有什么关系，比较相邻为什么可以一直传递成一个区间。
A1：填左边的 $i-1$ （小坑），$i$ 会被填好一部分，这一部分也是填 $i$ 的一个过程，在下一次循环时也可以顺便填好 $i+1$。
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+10;
int a[N];
signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0); cout.tie(0);
    int n,sum=0;
    cin>>n;
    for (int i=1;i<=n;i++)
        cin>>a[i];
    for (int i=1;i<=n;i++)
    {
        if (a[i]>a[i-1])
            sum+=a[i]-a[i-1];
    }
    cout<<sum;
    return 0;
}
```
