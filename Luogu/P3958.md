### P3958 [NOIP 2017 提高组] 奶酪
---

**难度**：$\mathit{\color{yellow}{普及}}$

**解法**：并查集。

**分析：**
- 注意到本体实际为一道三维连通性问题，且无向，故可以使用并查集解决。
- 遍历每两个洞，若其相切或相交，则将其合并。
- 建立一个哈希表，存储每个集合的最大高度和最小高度。
- 若存在一个集合既与底面相切或相交， 又和顶面相切或相交，则输出 `Yes`。若没有这样的集合，输出`No`。
- 注意：使用库函数 `sqrt` 计算 dist 会出现精度问题，应去掉开方。
此时距离的最大值为 $10^{9^2}=10^{18}$，应使用 `long long`。
```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e3 + 10;
typedef pair<int, int> PII;
struct Hole
{
    int x, y, z;
    bool operator < (const Hole & o) const
    {
        return z < o.z;
    }
} h[N];
int p[N];
int dist(Hole a, Hole b)
{
    int dx = a.x - b.x, dy = a.y - b.y, dz = a.z - b.z;
    return dx * dx + dy * dy + dz * dz;
}
int find(int x)
{
    if (p[x] != x)
        p[x] = find(p[x]);
    return p[x];
}
void merge(int a, int b)
{
    int ra = find(a), rb = find(b);
    if (ra != rb)
        p[ra] = rb;
}
signed main()
{
    int Q; cin >> Q;
    while (Q --)
    {
        int n, ht, r; cin >> n >> ht >> r;
        for (int i = 1; i <= n; i ++)
            cin >> h[i].x >> h[i].y >> h[i].z;
        for (int i = 1; i <= n; i ++)
            p[i] = i;
        for (int i = 1; i <= n; i ++)
            for (int j = i + 1; j <= n; j ++)
            {
                if (dist(h[i], h[j]) <= 4 * r * r)
                    merge(i, j);
            }
        unordered_map<int, PII> hash;
        for (int i = 1; i <= n; i ++)
        {
            int ri = find(i);
            if (hash.count(ri) == 0)
                hash[ri].second = h[i].z;
            hash[ri].second = min(hash[ri].second, h[i].z);
            hash[ri].first = max(hash[ri].first, h[i].z);
        }
        bool flag = 0;
        for (auto it = hash.begin(); it != hash.end(); it ++)
        {
            auto pos = it -> second;
            if (pos.first >= ht - r && pos.second <= r)
            {
                cout << "Yes\n";
                flag = 1;
                break;
            }
        }
        if (!flag)
            cout << "No\n";
    }
    return 0;
}
```
>由于本题为连通性问题，故也可使用搜索（DFS/BFS）解决，此处不再赘述。
